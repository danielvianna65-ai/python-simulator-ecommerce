# Python Ecommerce Simulator

Simulador de transações de um ecommerce usando Python,
responsável por alimentar um banco de dados relacional MySQL.

## Funcionalidades
- Geração de clientes, produtos e pedidos
- Simulação de fluxo de compra
- Atualização de estoque
- Agendamento de eventos (scheduler)
- Dados usados posteriormente em um pipeline de Data Engineering

## Tecnologias
- Python
- MySQL
- Faker (ou similar)

## Objetivo
Projeto educacional para simular um ambiente real de dados
utilizado em pipelines analíticos (Landing → raw → Silver → Gold).
